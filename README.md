# GLOSARIO-DASP

Glosario para DASP

# 1. Digitalización
Proceso de convertir información, procesos o activos analógicos (papel, mecánicos, etc.) a formato digital para facilitar su almacenamiento, procesamiento y análisis.

# 2.Transformación Digital
Cambio estratégico y cultural de una organización que utiliza tecnologías digitales para rediseñar procesos, modelos de negocio, experiencia del cliente y operaciones, generando mayor valor y competitividad.

# 3. IT
Conjunto de tecnologías, sistemas y servicios centrados en el manejo de datos e información: redes, servidores, software empresarial, ciberseguridad, bases de datos y aplicaciones de negocio.

# 4. OT
Sistemas y dispositivos que monitorizan y controlan procesos físicos e industriales en tiempo real (PLCs, SCADA, sensores, controladores de maquinaria, sistemas de producción).

# 5. Convergencia IT/OT
Integración de los sistemas de información (IT) con los de operación industrial (OT) para permitir el intercambio de datos, la visibilidad de punta a punta y la optimización de procesos productivos.

# 6. Automatización Industrial
Uso de sistemas de control (robots, PLCs, software) para operar maquinaria y procesos de fabricación con mínima intervención humana, aumentando eficiencia, precisión y seguridad.

# 7. Internet de las Cosas (IoT / IIoT)
Red de dispositivos físicos conectados que recopilan e intercambian datos. El IIoT (Industrial IoT) se enfoca específicamente en entornos industriales y de producción.

# 8. Infraestructura Tecnológica
Conjunto de hardware, software, redes, centros de datos, nube y servicios que soportan las operaciones digitales de una organización.

# 9. Modelo de Negocio Digital
Forma de crear, entregar y capturar valor basada en tecnologías digitales (plataformas, datos, servicios online, suscripciones, etc.), a menudo más flexible y escalable que los modelos tradicionales.
